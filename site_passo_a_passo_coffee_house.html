Contexto do projeto

Os estudantes irão desenvolver um site para uma cafeteria fictícia chamada Coffee House. O foco do projeto é divulgar produtos, apresentar a localização da cafeteria e facilitar o contato com os clientes.

O trabalho será realizado em equipes de 4 integrantes, aplicando conhecimentos básicos de HTML, CSS e responsividade.

Resumo da missão

Criar uma página web bonita, organizada, funcional e fácil de navegar para uma cafeteria fictícia.

Problema a ser resolvido

1

Organização da informação

O site precisa apresentar informações sobre produtos, localização e contato de maneira clara e objetiva.

2

Boa experiência do usuário

A navegação deve ser simples, intuitiva e agradável, permitindo que o visitante encontre rapidamente o que procura.

Foco da aula

HTML

Estruturação

Uso de títulos, parágrafos, imagens, links, listas, seções e organização semântica do conteúdo.

CSS

Estilização

Aplicação de cores, fontes, espaçamentos, bordas, sombras, alinhamento e layout visual.

UX

Usabilidade

Construção de uma interface simples, legível, acessível e fácil de utilizar.

R

Responsividade

Adaptação do site para diferentes tamanhos de tela, como computador, tablet e celular.

Passo a passo do projeto

Etapa 1 — Planejamento da equipe

Formem equipes com 4 integrantes e definam as funções de cada pessoa: criação do layout, desenvolvimento HTML, desenvolvimento CSS e apresentação/documentação.

Etapa 2 — Protótipo da interface

Criem um rascunho do site no Figma ou em papel. O protótipo deve mostrar onde ficarão o menu, o banner principal, os produtos, a localização e o contato.

Etapa 3 — Estrutura HTML

Montem a base da página usando HTML. Organizem o conteúdo em seções como cabeçalho, menu, produtos, sobre a cafeteria, localização, contato e rodapé.

Etapa 4 — Estilização com CSS

Escolham uma paleta de cores, fontes, espaçamentos e imagens que combinem com o tema de cafeteria. O visual deve ser agradável e coerente.

Etapa 5 — Responsividade

Adaptem o layout para funcionar bem em telas menores. Usem media queries, grids flexíveis e tamanhos proporcionais.

Etapa 6 — Testes e ajustes

Verifiquem se os links funcionam, se o texto está legível, se o layout não quebra no celular e se todas as informações importantes aparecem corretamente.

Etapa 7 — Apresentação final

A equipe deverá apresentar o site, explicar as escolhas de design, mostrar a divisão de tarefas e comentar os principais desafios encontrados.

Entregas dos estudantes

Ao final do projeto, cada equipe deverá entregar:

  • Protótipo da interface no Figma ou em papel.
  • Página web funcional desenvolvida com HTML e CSS.
  • Apresentação do projeto para a turma.
  • Breve documentação explicando as escolhas de design.
  • Descrição da divisão de tarefas entre os integrantes da equipe.

Forma de avaliação

Código

Organização, clareza e uso adequado de HTML e CSS.

Criatividade

Identidade visual, escolha de cores, imagens e composição.

Responsividade

Funcionamento correto em diferentes tamanhos de tela.

Funcionalidade

Navegação, links, seções completas e página funcionando.

Equipe

Participação dos integrantes e divisão equilibrada das tarefas.

Apresentação

Clareza ao explicar o processo, o resultado e as decisões tomadas.

Resultado esperado

Uma página web completa para a cafeteria Coffee House, com visual profissional, conteúdo organizado e navegação intuitiva.
